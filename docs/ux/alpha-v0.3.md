# Diretrizes de UX e Design — Alpha v0.3

## 1. Princípios Visuais
O Coonto preza por uma estética sóbria, elegante e de época, sem abrir mão da fluidez e modernidade digital:
- **Tipografia**: Serifas literárias clássicas aliadas a tipografia funcional limpa para menus e decisões.
- **Paleta de Cores**: Tons sépia, pergaminho, carvão e dourado envelhecido, transmitindo a atmosfera do século XIX.

## 2. Mapa Narrativo
O mapa não deve ser uma lista vertical simplória:
- Representa o fluxo das decisões com um eixo central machadiano (`◆`) e desvios alternativos (`◇`).
- Revelação progressiva (névoa de descoberta com nós `?`).
- Indicador visual claro de onde o leitor se encontra no momento.

## 3. Experiência de Áudio
- **Sem player ostensivo**: Proibido player com timeline pesada ou controles poluídos na tela de leitura.
- **Controle Minimalista**: Apenas um ícone discreto:
  - `▶` para iniciar reprodução.
  - `⏸` para pausar.
- Arquitetura preparada para receber arquivos de locução profissional em `public/audio/o-alienista/` (ex: ElevenLabs ou gravação humana).

## 4. Integração de Imagens
- As imagens não são meros enfeites: cada imagem apoia o ambiente, o peso dramático e a contextualização pedagógica.
- Coerência visual rigorosa entre iluminação, vestimentas e arquitetura oitocentista.
