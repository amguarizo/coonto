COONTO ALPHA v0.3 — VERTICAL SLICE
===================================

OBJETIVO
-------
Primeira sequência de qualidade próxima da experiência final, usando
a Revolta dos Canjicas como vertical slice.

COMO TESTAR NO WINDOWS
----------------------
1. Extraia a pasta.
2. Clique duas vezes em INICIAR_COONTO.bat.
3. O navegador abrirá index.html diretamente.
Não precisa de Python nem localhost.

O QUE ESTA VERSÃO MUDA
----------------------
- Textos narrativos mais densos.
- Imagens reais integradas ao Alpha, derivadas da direção visual aprovada.
- Áudio reduzido a um único ícone ▶ discreto.
- Voz de demonstração usa Speech Synthesis do navegador.
- Estrutura pronta para substituir a voz por MP3/OGG de ElevenLabs.
- Decisão → consequência → E Machado? → pedagogia → mapa.
- Mapa narrativo em SVG, com ramificações reais e caminho do usuário.
- Aplicativo estático, portanto pronto para Nginx/Apache.

------------------

  assets/audio/revolta-abertura.mp3

A interface não muda: continua apenas o ícone ▶.

PUBLICAÇÃO EM LINUX / NGINX
---------------------------
Sugestão:
  /var/www/coonto-alpha

Copie o conteúdo desta pasta para esse diretório.
Há um arquivo:
  nginx-alpha.coonto.com.br.conf

Ele é um modelo de virtual host para:
  alpha.coonto.com.br

Depois o DNS do subdomínio deve apontar para o IP público do servidor.
Quando o IP e a distribuição Linux estiverem definidos, podemos fechar os
comandos exatos de instalação, Nginx e HTTPS.
